# Tradução do Anope para português brasileiro

Catálogo de tradução do Anope para `pt_BR`, mantido pela equipe da rede
vIRCio.net.

## Versão

Esta tradução foi migrada para a série **Anope 2.1.x**, tendo como base o
Anope 2.1.27. O catálogo contém 1.905 mensagens traduzidas, incluindo as
formas plurais aplicáveis ao português brasileiro.

## Validação

O catálogo pode ser validado com GNU gettext:

```sh
msgfmt --check --check-format --statistics -o /dev/null anope.pt_BR.po
```
